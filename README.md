# 國小社會領域 AI 備課島 (Taiwan Social Studies AI Prep Island)

## 📌 專案願景與定位

**國小社會領域 AI 備課島** 是一個專為國小社會科教師設計的**遊戲化、視覺化微縮知識地圖備課系統**。

本子專案將原本嚴肅抽象的「108 社會領域課綱」、「12 大探究思維策略」與「AI 備課實作工具」，轉化為一座充滿探索趣味的童趣浮空島嶼。教師透過「雙軌解鎖闖關機制」（課綱理論探索 ⮂ AI 實作應用），逐步解鎖知識節點與強大備課工具，實現寓教於樂、增能減負的備課體驗。

## 🧭 核心模組功能介紹

### 1. 3D 概念預覽與互動島嶼 (`國小社會備課島_3D預覽.html`)
* **微縮視角場景**：以高解析度 3D 微縮地圖為背景，搭載透視深度動態光影與點位脈衝光環。
* **雙軌通關解鎖機制**：
  * **課綱認知軌（左側知識之泉）**：引導教師理解總綱核心素養、學習表現三大面向（理解、思維、實踐）與學習內容四大主題（互動、多元、變遷、正義）。
  * **AI 實作應用軌（右側工匠之坊）**：串接「課本跨頁提問生成平台」與「素養導向學習單生成平台」，達成即學即用的實戰轉化。
* **互動抽屜面板**：點擊各島嶼地標即刻展開對應任務目標、課綱解析、提示問答與解鎖按鈕。
* **單檔獨立版 (`dist/國小社會備課島_3D預覽_standalone.html`)**：底圖以 Base64 編碼內嵌，單一 HTML 即可發布給各校研習教師，無需依賴外部圖檔伺服器。

### 2. 繪本插畫風地圖 (`國小社會備課島.html`)
* 純 CSS 與向量風打造的溫暖海洋島嶼，適合作為低年級或入門教學情境之視覺載體。

### 3. 108 課綱精華導覽 (`108課綱國小社會領域精華導覽.html`)
* 收錄第二、三學習階段的核心素養條目（社-E-A1 至 社-E-C3）與三大面向簡介，具備一鍵返回備課島之導航連結。

### 4. 學習重點完整收錄表 (`108課綱國小社會領域學習重點完整收錄表.html`)
* 將教育部 108 社會領域課綱官方條目全數收錄，支援即時關鍵字過濾搜尋與跨學習階段對照。

## 🛠 技術棧與架構特點

* **零建置依賴 (Zero-build Dependency)**：純原生 HTML5 + JavaScript (ES6+)，無需 Node.js、npm 或打包工具，直接於任何現代瀏覽器開啟。
* **樣式框架**：Tailwind CSS (CDN) + 自訂立體按鈕與卡通厚邊框陰影 (`btn-pop`)。
* **字型與圖標**：Google Fonts (Noto Sans TC, M PLUS Rounded 1c) 與 FontAwesome 6。
* **資料儲存**：客戶端 `localStorage` 記錄教師闖關進度與成就徽章，保障教師隱私且離線可用。

## 🚀 快速啟動

1. **直接預覽**：
   * 進入 `dist/` 或 `src/` 目錄。
   * 雙擊開啟 `國小社會備課島_3D預覽.html` 或 `國小社會備課島_3D預覽_standalone.html`。
2. **分享發布**：
   * 若需發送給其他教師或上傳至 Google 雲端硬碟/網頁空間，建議優先使用 `dist/國小社會備課島_3D預覽_standalone.html`。
